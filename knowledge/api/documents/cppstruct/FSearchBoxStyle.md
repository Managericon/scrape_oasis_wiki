# FSearchBoxStyle

Represents the appearance of an SSearchBox

## Variables

| Name | Type/Value | Description |
|---|---|---|
| `TextBoxStyle` | `FEditableTextBoxStyle` | Style to use for the text box part of the search box |
| `ActiveFontInfo` | `FSlateFontInfo` | Font to use for the text box part of the search box when a search term is entered |
| `UpArrowImage` | `FSlateBrush` | Image to use for the search "up" arrow |
| `DownArrowImage` | `FSlateBrush` | Image to use for the search "down" arrow |
| `GlassImage` | `FSlateBrush` | Image to use for the search "glass" |
| `ClearImage` | `FSlateBrush` | Image to use for the search "clear" button |
| `ImagePadding` | `FMargin` | Padding to use around the images |
| `bLeftAlignButtons` | `bool` | If true, buttons appear to the left of the search text |
