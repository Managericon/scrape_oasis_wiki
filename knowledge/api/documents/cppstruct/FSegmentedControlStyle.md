# FSegmentedControlStyle

Represents the appearance of an SSegmentedControl

## Variables

| Name | Type/Value | Description |
|---|---|---|
| `ControlStyle` | `FCheckBoxStyle` | The style to use for our Center Control |
| `FirstControlStyle` | `FCheckBoxStyle` | The style to use for our Left Control |
| `LastControlStyle` | `FCheckBoxStyle` | The style to use for our Left Control |
| `BackgroundBrush` | `FSlateBrush` | Background of the segmented control |
| `UniformPadding` | `FMargin` | Padding between each control |
