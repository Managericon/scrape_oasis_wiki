# FPrimaryAssetId

This identifies an object as a "primary" asset that can be searched for by the AssetManager and used in various tools

## Variables

| Name | Type/Value | Description |
|---|---|---|
| `PrimaryAssetType` | `FPrimaryAssetType` | The Type of this object, by default it's base class's name |
| `PrimaryAssetName` | `FName` | The Name of this object, by default it's short name |
