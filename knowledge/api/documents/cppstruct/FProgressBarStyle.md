# FProgressBarStyle

Represents the appearance of an SProgressBar

## Variables

| Name | Type/Value | Description |
|---|---|---|
| `BackgroundImage` | `FSlateBrush` | Background image to use for the progress bar |
| `FillImage` | `FSlateBrush` | Foreground image to use for the progress bar |
| `MarqueeImage` | `FSlateBrush` | Image to use for marquee mode |
