# FAnchors

Describes how a widget is anchored.

## Variables

| Name | Type/Value | Description |
|---|---|---|
| `Minimum` | `FVector2D` | Holds the minimum anchors, left + top. |
| `Maximum` | `FVector2D` | Holds the maximum anchors, right + bottom. |
