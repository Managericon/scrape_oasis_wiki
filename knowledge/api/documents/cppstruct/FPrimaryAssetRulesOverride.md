# FPrimaryAssetRulesOverride

Simple structure to allow overriding asset rules for a specific primary asset. This can be used to set chunks

## Variables

| Name | Type/Value | Description |
|---|---|---|
| `PrimaryAssetId` | `FPrimaryAssetId` | Which primary asset to override the rules for |
| `Rules` | `FPrimaryAssetRules` | What to overrides the rules with |
